# Carryon

Rigid body physics simulation in Minecraft utilizing the [LibBulletjme](https://github.com/stephengold/Libbulletjme)
 library. adds JNI "glue code"
to portions of [Bullet Physics][bullet]
and [Khaled Mamou's V-HACD Library][vhacd],
enabling 3-D physics simulation for Java applications.

A fork of [Rayon](https://github.com/LazuriteMC/Rayon) to continue the project exclusively for Forge.
The old project was archived, so we carry on!

## Examples
See the [examples folder](https://github.com/jakeee51/Carryon/tree/1.20.1/src/main/java/dev/lazurite/rayon/example) for an example

[bullet]: https://pybullet.org/wordpress "Bullet Real-Time Physics Simulation"
[vhacd]: https://github.com/kmammou/v-hacd "V-HACD Library"
